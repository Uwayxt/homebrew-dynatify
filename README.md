# Homebrew Tap for Dynatify 🏝️

Official Homebrew Cask tap for [Dynatify](https://github.com/Uwayxt/Dynatify) — Dynamic Island & Real-Time Synced Lyrics for Spotify & Apple Music on macOS by [@uwayxt](https://github.com/uwayxt).

## Installation

```bash
brew tap uwayxt/dynatify
brew install --cask dynatify
```

## Update

```bash
brew upgrade --cask dynatify
```
